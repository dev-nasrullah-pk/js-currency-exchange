# 💱 Professional Currency Converter

A modern, responsive, and dynamic Currency Converter web application built with vanilla JavaScript, HTML5, CSS3, and real-time exchange rate APIs.

## 🚀 Features

* **Real-Time Exchange Rates:** Fetches live, accurate currency rates using Exchange Rate API.
* **30+ Major Currencies:** Supports dropdown selection for over 30 global currencies (USD, PKR, INR, EUR, GBP, SAR, AED, etc.) for both base and target selections.
* **Dynamic Calculations:** Instant conversion based on user input amounts with precision formatting (decimal rounding to 2 places).
* **Robust Error Handling:** Detects invalid or empty amount inputs and handles network/connection failures gracefully.
* **Clean & Modern UI:** Designed with a sleek layout, custom select dropdowns, and soft gradients.

## 🛠️ Tech Stack

* **HTML5:** Semantic document structure.
* **CSS3:** Custom styles, Flexbox layouts, gradients, and responsive card design.
* **JavaScript (ES6+):** Asynchronous JavaScript (`async/await`, `fetch` API), DOM manipulation, and event handling (`change`, `click`).
* **API:** ExchangeRate-API (`v6/latest/...`)
