A modern and responsive Currency Converter web app built using HTML, CSS, and JavaScript.
# 💱 CurrencyCraft

A sleek, responsive, and fast real-time currency converter web application designed with a professional slate/blue UI aesthetic. Built as part of my frontend development journey to master API integration and DOM manipulation.

## 🚀 Features
- **Real-Time Exchange Rates:** Fetches live data securely using the Open Exchange Rates API (`async/await` & `Fetch API`).
- **Multi-Currency Support:** Supports conversions for **PKR, INR, and SAR** with dynamic currency symbols.
- **Interactive UI/UX:** Features interactive active-state currency buttons, smooth hover transitions, and custom SVG icons.
- **Mobile-First & Responsive:** Fully optimized layout that adapts seamlessly across all screen sizes.

## 🛠️ Tech Stack
- **HTML5** (Semantic markup)
- **CSS3** (Flexbox, custom styling, state transitions)
- **Vanilla JavaScript** (ES6+, asynchronous programming, DOM manipulation)
- **API:** Open Exchange Rates API (`v6/latest/USD`)

## 💡 What I Learned
Through this project, I strengthened my core JavaScript logic handling asynchronous requests, managing global state variables, and building clean, component-based CSS layouts from scratch without heavy UI frameworks.
